# ``list``

`std::list` 是 C++ 标准模板库（STL）中的**双向链表**容器，定义在 `<list>` 头文件中。

<hr />

## 基本特点

```cpp
#include <list>
std::list<int> myList = {1, 2, 3, 4, 5};
```

<hr />

## 核心特性

<br />

### 1. 底层结构：双向链表

每个节点包含数据、指向前一个节点的指针和指向后一个节点的指针。

<br />

### 2. 时间复杂度

| 操作 | 复杂度 | 说明 |
|------|--------|------|
| 插入/删除（已知位置） | O(1) | 任意位置快速插入删除 |
| 随机访问 | O(n) | **不支持** `[]` 下标访问 |
| 查找元素 | O(n) | 需要遍历 |

<br />

### 3. 迭代器稳定性

插入和删除操作**不会使已有迭代器失效**（除被删除元素自身的迭代器），这是相对 `vector` 的一大优势。

<hr />

## 常用操作

```cpp
std::list<int> lst = {3, 1, 2};
lst.push_back(4);        // 尾部插入
lst.push_front(0);       // 头部插入
lst.insert(it, 10);      // 在迭代器位置插入
lst.pop_back();          // 删除尾部元素
lst.remove(2);           // 删除所有值为 2 的元素
lst.sort();              // 排序（成员函数，非 std::sort）
lst.unique();            // 去除相邻重复元素
lst.merge(other);        // 合并两个有序链表
lst.reverse();           // 反转
lst.splice(it, other);   // 将 other 拼接到 it 位置
```

<hr />

## list vs vector

| 对比项 | list | vector |
|--------|------|--------|
| 内存布局 | 非连续 | 连续 |
| 随机访问 | ❌ O(n) | ✅ O(1) |
| 中间插入删除 | ✅ O(1) | ❌ O(n) |
| 缓存友好性 | 差 | 好 |
| 头部插入 | O(1) | O(n) |

<hr />

## 适用场景

- ✅ 需要频繁在**任意位置插入/删除**元素
- ✅ 需要保持迭代器稳定
- ✅ 无需随机访问
- ❌ 元素数量少或以遍历访问为主时，`vector` 通常更快（缓存友好）

另外，如果只需要头尾操作，可以考虑更轻量的 `std::deque` 或 `std::forward_list`（单向链表）。
