## Usage

- Browse the folders in Visual Studio, VS Code, or another C++ editor.
- Copy a suitable template into a problem solution and adapt the input, constraints, and algorithm.
- Compile one source file at a time; this repository has no shared build system or runtime.

```powershell
g++ -std=c++17 -O2 -Wall -Wextra -o .\tmp_solution.exe ".\path\to\solution.cpp"
& .\tmp_solution.exe
```

For C sources, use gcc -std=c11 -O2 -Wall -Wextra. Temporary executables are local verification artifacts and should not be committed.
