# 洛谷 P2678（跳石头） vs P3853（路标设置）

先把两题各用一句话钉住：

- **P2678（NOIP2015 D2T1）**：[0, L] 上有 N 块石头（两端 0 和 L 不可动），至多移走 M 块，让**最小**跳跃间距尽量**大**。
- **P3853（TJOI2007）**：[0, L] 上有 N 个既有路标（含两端），至多增设 K 个（整数位置），让**最大**相邻间距尽量**小**。

它们是二分答案里著名的一对**镜像题**：一个“删点让最小值变大”，一个“加点让最大值变小”。

<hr />

## 相通之处

1. **都是二分答案**：把优化问题转化为判定问题——“给定 x，预算内能否让所有间距 ≥ x（P2678）/ ≤ x（P3853）？”可行性关于 x 单调，在 [1, L] 上二分即可，复杂度都是 O(N log L)。
2. **check 都是“贪心数最少操作次数，再与预算比大小”**：不需要构造方案，只需算出“最少删几块 / 最少加几个”，和 M / K 比较。
3. **处理对象都是排序点列的“相邻间距”**，预算都是“至多”型。
4. **都很难绕开二分直接贪心**：比如 P3853 里“每次拆分当前最大空隙”的贪心是错的（长 10 的空隙加 2 个路标：贪心得 max=5，最优是拆成 4,3,3 得 max=4），所以二分几乎是唯一自然解法。

<hr />

## 不同之处

| | P2678 跳石头 | P3853 路标设置 |
|---|---|---|
| 模型 | 最小值最大化 | 最大值最小化 |
| 操作 | 删点（点集变稀疏） | 插点（点集变稠密） |
| 二分方向 | x 越大越难，check 由真变假，求**最大**可行 x | x 越大越易，check 由假变真，求**最小**可行 x |
| check 结构 | **带状态的顺序贪心** | **无状态的分段计数** |
| 几何效果 | 删点 = 相邻两段**合并**，决策互相影响 | 插点 = 一段**分裂**成两段，各段独立 |
| 典型坑点 | 终点不可删，末段到终点的距离也要达标 | 新路标必须是整数位置；d 是 x 的倍数时别多数 1 个 |

**最核心的差别在 check 的结构**，根源就是“删”与“加”这两个相反操作：

- 删一块石头会把左右两段**合并**，所以“这块删不删”取决于上一块保留在哪——决策有链式依赖，必须从左到右扫描并维护状态。遇到间距不足时删**当前**（靠右）那块不劣于删前一块（交换论证：把空间留给后面）。
- 加一个路标只把它所在的空隙**一分为二**，与其他空隙毫无关系——所以每段长 d 的需求是闭式 **⌈d/x⌉ − 1**（即 ⌊(d−1)/x⌋），直接求和。

## check 代码对照

```cpp
// P2678：能否删 ≤m 块，使所有间距 ≥ x
bool check(int x) {
    int cnt = 0, now = 0;              // now：上一块未被移走的石头
    for (int i = 1; i <= n; i++) {
        if (a[i] - now < x) cnt++;     // 贴太近 → 移走当前这块
        else now = a[i];
    }
    if (L - now < x) cnt++;            // 终点删不得，必要时把最后保留的那块也删掉
    return cnt <= m;
}
```
```cpp
// P3853：能否增设 ≤k 个，使所有间距 ≤ x
bool check(int x) {
    long long cnt = 0;
    for (int i = 1; i <= n; i++)        // a[1]=0, a[n]=L
        cnt += (a[i] - a[i-1] - 1) / x; // 长为 d 的空隙需要 ⌈d/x⌉-1 个
    return cnt <= k;
}
```
对比一眼可见：一个有 `now` 这个状态变量和分支逻辑，一个是纯求和公式。

两点补充：

- P2678 那句 `if (L - now < x) cnt++;` 很多人不写也能 AC（数据没卡到），但它是必要的：例如 L=10、石头在 4 和 8、M=1、x=5 时，必须两块全删才可行，不补这句会误判可行。
- P3853 的计数写成 `d / x` 是常见手滑：当 d 恰好是 x 的倍数时会多数 1（如 d=10, x=5 只需 1 个，`10/5=2` 就错了），`⌊(d-1)/x⌋` 才对。

<hr />

## 一句话总结

两题共享“**二分答案 + 贪心判定**”的骨架，而“删”与“加”这对镜像操作把全部差异挤进了 check：一个是**有后效的链式贪心**，一个是**相互独立的分段求和**。把这两题连着做，正好检验你是不是真的会“写 check”，而不是只背了二分模板。
